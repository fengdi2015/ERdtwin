# Suite 203 Clinic Planner

Interactive browser-based clinic floor-plan planner for 40 Dale Road, Suite 203.

## Run locally

Open `interior_planner_5.html` in a modern web browser. The HTML file and the included image files must remain in the same directory.

## Included

- 2D floor-plan editing, dimensions, doors, measurement tools, and wheelchair-fit simulation
- Room reference photos and room-aware clinical planning summaries
- Equipment inventory with product details, photos, dimensions, and procurement links
- Marketing, patient access, referral, pharmaceutical-representative, and placement guidance

## Notes

Planning suggestions are operational aids, not code, engineering, clinical, privacy, or legal approval. Confirm site conditions and applicable requirements before construction, purchasing, or clinical use.
